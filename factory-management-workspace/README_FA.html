راهنمای اجرای فضای مشاوره مدیریت

  1. فایل ZIP را کاملاً از حالت فشرده خارج کنید.
  2. فایل index.html را در Chrome یا Edge باز کنید. در ویندوز می‌توانید روی START-WINDOWS.bat هم دوبار کلیک کنید.
  3. برنامه و فونت بدون اینترنت اجرا می‌شوند؛ نصب نرم‌افزار یا کتابخانه لازم نیست.

جمع‌بندی و نگهداری اطلاعات

اطلاعات هنگام ثبت در مرورگر ذخیره می‌شوند و با Refresh باقی می‌مانند. برای ادامه جلسه از همان مرورگر و همان مسیر پوشه استفاده کنید.

در بخش «جمع‌بندی مدیریتی»، «ایجاد جمع‌بندی جلسه» را بزنید. برای خروجی PDF، «چاپ / ذخیره PDF» و سپس Save as PDF را انتخاب کنید. یادداشت‌های مشاور وارد این خروجی نمی‌شوند.

برای دریافت تمام اطلاعات ثبت‌شده، دکمه «دریافت فایل اطلاعات جلسه» یک فایل JSON می‌دهد. «شروع جلسه جدید» پس از تأیید، اطلاعات جلسه قبلی را پاک می‌کند.
